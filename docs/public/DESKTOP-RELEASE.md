# H3 AI Computer · Desktop Preview 0.4

**내 컴퓨터의 AI가 기본입니다. 필요할 때만 온라인 AI를 선택하세요.**

- Windows x64: download `H3-Windows-x64.zip`, extract and run `h3-ai-computer.exe`.
- Linux x64: extract `H3-Linux-x64.tar.gz`, run `h3-ai-computer`. A graphical desktop and compatible system libraries are required. Keep the packaged Chromium sandbox intact; do not use `--no-sandbox` as installation advice.
- macOS Apple Silicon: extract `H3-macOS-arm64.tar.gz` for the shared desktop app. `H3-Mac-0.4.0-preview.zip` is the separate native SwiftUI app.

These portable Preview packages are not publicly code-signed/notarized; OS launch protection may require review. Models and runtimes are installed separately. SHA256 files are included beside downloads.

Local chat and agent, model discovery/download, optional OpenRouter APIs, Codex/Claude planner adapters, scoped text tools, generation preparation and job records. Explicit online actions never replace the local default automatically.

OS build and native launch tests do not certify every GPU/model. MLX/Metal media engines require Apple Silicon; Windows/Linux can connect compatible local APIs or OS-specific runtimes. See the repository desktop guide for exact support and remaining productization work.
